Health Connect Viewer

Online maps for workout routes

When this is on, the page downloads map images for the route you're looking at. Those requests tell the map provider which area your route covers, along with your IP address. None of your health data is sent, and everything else stays offline. Turn it off at any time.

Settings

Goals

Shown as a dotted line on the matching charts. Leave a box empty for no goal.

Heart-rate zones

Leave empty to estimate it from your highest recorded heart rates.

Memory use

Low-memory mode keeps a temporary copy of the export in this browser's private storage and reads it from there. It's deleted when you open another file, and whenever the viewer starts. Browsers only allow this storage for pages served from a website (like the online copy). When the page is opened as a file, the export is always held in memory.

Open your Health Connect export

Drop Health Connect.zip (or the .db file inside it) here, or

Getting the file: on your phone open Settings → search "Health Connect" → Manage data → Backup and restore → Scheduled export. After the first export runs, download the zip from the cloud storage you picked.

Also accepted: workout files (GPX, TCX, FIT) and an OpenVitals cycle-journal backup (.json). Add them along with the export, or later with "Add files".

Everything is read inside this browser tab. This page contains everything it needs (database engine included) and is locked so it cannot connect to the internet (unless you turn on online maps for workout routes).
